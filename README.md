## 🧭 About the Project

**Travel With Me** is a frontend travel website created using **HTML and CSS**.

The website includes:

- 🏠 Home page
- 📍 Places page
- 📝 Booking page
- 👤 Sign Up page
- 🎥 Glimpse page
- 🖼️ Travel images
- 🔗 Navigation between pages
